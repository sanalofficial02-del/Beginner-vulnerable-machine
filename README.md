# Beginner Vulnerable Machine

A beginner-friendly intentionally vulnerable Linux virtual machine for cybersecurity learning and pentesting practice.

---

## Download

Download the VirtualBox VM here:

https://drive.google.com/file/d/1dlcrpLp-izurPTNzRs099VO6Qh3aPtV0/view?usp=drive_link

## Import Into VirtualBox

1. Download the `.ova`
2. Open VirtualBox
3. File → Import Appliance
4. Select the `.ova`
5. Start the VM

---

- 21 FTP
- 22 SSH
- 80 HTTP
